# Bangladesh Motocross Club & Academy Website

Open `index.html` in a browser to preview the website.

The `images` folder contains the club logo and the uploaded photos used by the site.

To publish it online, upload the whole folder to a web host, or use a static hosting service such as GitHub Pages, Netlify, or Cloudflare Pages.

Before publishing, replace/add:
- verified championship titles and official race results
- official address (if desired)
- any additional social links
- academy schedule, fees and registration details
